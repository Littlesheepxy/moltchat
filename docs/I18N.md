# MoltChat 国际化使用指南

## 已支持的语言

- 🇺🇸 English (en)
- 🇨🇳 中文 (zh)
- 🇯🇵 日本語 (ja)
- 🇰🇷 한국어 (ko)
- 🇪🇸 Español (es)
- 🇧🇷 Português (pt)
- 🇸🇦 العربية (ar)

## 主题色

主色调：`#DF3B2D` (HSL: 5, 74%, 52%)

## 如何使用翻译

### 1. 在客户端组件中使用

```tsx
'use client';

import { useI18n } from '@/lib/i18n-provider';

export function MyComponent() {
  const { t } = useI18n();

  return (
    <div>
      <h1>{t('landing.title')}</h1>
      <p>{t('landing.subtitle')}</p>
      <button>{t('common.save')}</button>
    </div>
  );
}
```

### 2. 使用语言切换按钮

```tsx
import { LocaleToggle } from '@/components/locale-toggle';

// 在你的组件中
<LocaleToggle />
```

### 3. 使用主题切换按钮

```tsx
import { ThemeToggle } from '@/components/theme-toggle';

// 在你的组件中
<ThemeToggle />
```

## 翻译文件结构

所有翻译文件位于 `messages/` 目录：

```
messages/
├── en.json  # 英文
├── zh.json  # 中文
├── ja.json  # 日文
├── ko.json  # 韩文
├── es.json  # 西班牙语
├── pt.json  # 葡萄牙语
└── ar.json  # 阿拉伯语
```

## 添加新的翻译键

1. 在 `messages/en.json` 中添加新的键值对
2. 在所有其他语言文件中添加对应的翻译
3. 使用 `t('your.new.key')` 访问翻译

## 特性

✅ 客户端语言切换（无需刷新页面）
✅ 语言偏好保存到 localStorage
✅ 7 种语言支持
✅ 亮暗主题切换
✅ 主题色 #DF3B2D
✅ 下拉菜单选择语言
✅ 主题跟随系统设置

## 注意事项

- 语言切换是客户端实现，不会改变 URL
- 用户的语言偏好会保存在浏览器本地
- 首次访问默认使用英文
- 阿拉伯语暂未实现 RTL（从右到左）布局，可以后续添加
